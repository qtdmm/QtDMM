Package repositories

The signed Flatpak repository of QtDMM, the multimeter readout and recorder

Flatpak

For any Linux with Flatpak (x86_64). QtDMM comes from here, signed with the QtDMM key; the KDE runtime it needs comes from Flathub. Once added, flatpak update brings each new release.

Add the repository and install QtDMM:

flatpak remote-add --user --if-not-exists qtdmm https://qtdmm.github.io/QtDMM/repos/flatpak/qtdmm.flatpakrepo
flatpak install --user qtdmm io.github.qtdmm.qtdmm//stable

Or in one step, with a software centre that opens io.github.qtdmm.qtdmm.flatpakref.

Release candidates are on the branch beta (flatpakref): flatpak install --user qtdmm io.github.qtdmm.qtdmm//beta

Meters on USB HID (UNI-T UT803, UT61E with the HID cable, ...) need the udev rule of QtDMM on the computer, as without Flatpak: see INSTALL.

The key

The repository is signed with the QtDMM repository key: qtdmm.gpg. qtdmm.flatpakrepo carries it already; Flatpak refuses anything not signed with it.

Its fingerprint (RSA 4096, valid until 17 October 2029):

1F24 BD3C 3706 6077 1957  AB09 70AE 0699 0663 233B

To compare: curl -fsSL https://qtdmm.github.io/QtDMM/repos/qtdmm.gpg | gpg --show-keys --with-fingerprint
